# [エラー・症状]の原因と解決方法

## 結論

原因と解決方法を最初に簡潔に示す。

## 発生した問題

何が起きたかを書く。

### 症状

```text
error / log
```

### 発生条件

- Environment:
- Version:
- Configuration:

### 影響

何ができなくなったかを書く。

## 調査

原因を特定するまでの過程を書く。

### 仮説1

なぜそう考えたか。

```text
確認したコマンド・コード
```

結果を書く。

仮説が間違っていた場合も、その事実を残す。

### 仮説2

同様に記録する。

## 原因

最終的に特定した原因を書く。

「何が悪かったか」だけでなく、「なぜその症状になったか」まで説明する。

## 解決方法

実際に行った修正を書く。

```text
code / config
```

なぜこの変更で解決するのか説明する。

## 動作確認

```text
command / result
```

修正後に問題が解消した証拠を示す。

## 再発防止

必要であれば、Test、Lint、監視、設計変更などの再発防止策を書く。

## まとめ

- 症状
- 原因
- 解決方法
- 得られた教訓

を簡潔にまとめる。
