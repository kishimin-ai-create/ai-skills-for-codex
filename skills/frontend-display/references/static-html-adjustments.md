# 既存HTML資料の表示調整

対象HTML、指定色、表示・削除対象、保存先の指定を確認する。内容を読むための出典確認と、今回依頼された表示変更を区別する。

- 公式カラーなど外部の根拠が必要な色は一次資料で確認する。名称だけが定義されている場合、画面用の色コードは近似であり公式の数値とは扱わない。
- グラデーションは指定された方向と始点・終点を保つ。複数人を扱うカードでは、人物と配色の対応を崩さず、分割・併記など既存の構造に合う表現を選ぶ。解釈が結果を大きく変える場合だけ確認する。
- 全体背景とカードの配色を別々に扱う。文字、リンク、フォーカスが背景に埋もれないかを確認する。
- 削除指定された説明は再挿入しない。調査手順、内部パス、検証件数などの作業報告は、表示が依頼されない限りHTML本文へ追加しない。必要な出典表示や依頼された本文まで一括削除しない。
- 「おすすめ」と「訪問記録」など、元資料で異なる意味を外観修正に伴って書き換えない。新しい体験談、出典、現在の営業情報は補作しない。
- 保存・移動・コミットの指定を守る。HTML編集だけの依頼からファイル移動や公開を追加しない。

表示確認では代表的な幅で配色の向き、人物との対応、折り返し、はみ出し、削除文言を確認する。ブラウザが利用できなければ、静的確認と表示未確認を区別して報告し、見たことにしない。
