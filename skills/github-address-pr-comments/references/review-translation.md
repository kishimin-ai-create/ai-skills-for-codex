# レビュー指摘の翻訳

入力は指摘本文と訳先言語。後から言語の訂正があれば最新の指定を採る。訳先が不明で文脈からも決まらない場合だけ確認する。

翻訳文だけを返す。原文の条件、失敗の影響、指摘の確度、推奨対応を保ち、コード、識別子、URL、HTTPステータスは変更しない。説明、修正案、反論、返信文を付け足さない。

たとえば「型チェックを通るが実行時に不整合が生じる」という指摘を、「型エラーになる」と訳さない。明らかな誤記でも、契約のキー名など技術的な意味を変える修正は翻訳と混ぜない。

## コピー用の依頼テンプレート

```text
以下のレビュー指摘を日本語に翻訳してください。翻訳文だけを返してください。
コード・識別子・URLは保持してください。

<レビュー指摘本文>
```
