# Candidate Rubric

Score each normalized task group from 0 to 2 for each dimension. Scores are evidence summaries, not a mechanical authorization to edit files.

| Dimension | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Frequency | one occurrence | two occurrences or one repeated session | three or more independent occurrences |
| Procedural stability | materially different each time | shared outline with variable steps | same decision sequence and checks |
| Repeated inputs/outputs | no stable boundary | partially repeated files or prompts | stable input and output contract |
| Judgment required | mostly bespoke judgment | bounded choices | deterministic with explicit exceptions |
| Error cost | low and easily reversible | moderate rework | costly, unsafe, or frequently forgotten |
| Cross-session value | no resume benefit | useful across sessions | clearly needed across dates or PCs |

## Classification guidance

- `skill`: usually total score 8 or higher, with at least 1 for frequency and procedural stability, and a clear trigger phrase.
- `checklist/template`: usually total score 5–9 when judgment remains significant or the procedure is not yet stable enough for automation.
- `AI configuration`: recurring omissions across unrelated domains, where the fix belongs in global behavior rather than one workflow.
- `manual/insufficient evidence`: total score below 5, one-off work, or unresolved ownership/scope.

These thresholds are defaults. Explain any exception and cite the log evidence that justifies it.
