# 不具合Issue本文

リポジトリ固有の不具合テンプレートがない場合に使う。

```markdown
## 現象

<何が起きているか。影響する機能と実際の結果を書く>

## 再現手順

1. <初期状態>
2. <操作>
3. <次の操作>
4. <観測結果>

## 期待する動作

<同じ操作で本来どうなるべきか>

## 対象ブラウザ

- [ ] Chrome
- [ ] Firefox
- [ ] Safari
- [ ] Edge
- [ ] ブラウザ非依存
- [ ] 未確認

## 環境・検証結果

- バージョン: <確認済みの値、または未確認>
- OS: <確認済みの値、または未確認>
- 再現結果: <実行コマンドとpass/fail、または未実行>

## 補足

<最小限のログ、スクリーンショット、関連Issue。なければ「なし」>
```

## 記入規則

- 原因ではなく観測した現象を主文にする。
- 再現に不要なログを省略する。
- エラー全文が長い場合は特徴的な行だけを引用する。
- ブラウザを確認していない場合は「未確認」を選ぶ。
